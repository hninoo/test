# SSO設定マニュアル

このディレクトリには以下のマニュアルファイルを配置してください：

## 必要なファイル

-
`google_saml_setup.pdf` -
Google
SAML設定のマニュアル
-
`ms365_saml_setup.pdf` -
Microsoft
365
SAML設定のマニュアル

## 配置方法

1.
実際のSSO設定マニュアルのPDFファイルを作成
2.
上記ファイル名で本ディレクトリに配置
3.
SSO設定画面からダウンロードリンクが機能するようになります

## 注意事項

-
ファイル名は正確に上記の通りにしてください
-
PDFファイルのサイズは適切に圧縮してください
-
内容にはセキュリティ情報が含まれる可能性があるため、アクセス権限に注意してください
